about the zoo

These sites mostly build themselves. Tag @buildthis.bisks.net on Bluesky with an idea and a bot writes one, deploys it, and replies with the link. These pages show that happening:

  • directory everything shipped, and what's still queued
  • logs every tag and what became of it — built, failed, or ignored
  • timeline the same story from the git history, commit by commit
  • health is the builder alive, is anything backed up or broken
  • watchtower every site checked from outside — serving, and serving the right bytes
  • lexicons every net.bisks.* record schema a site writes, in one place
  • source one monorepo, one directory per site, MIT
