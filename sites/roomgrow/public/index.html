roomgrow

A script that elaborates one Room World room for as long as it runs. Every minute it makes one small change: a new shape, a nudged pillar, a recoloured torus, another sound, a new name. Each draft is compiled with the room's check_shader first, so a bad roll never reaches the room.

Run it

curl -so grow.mjs https://roomgrow.bisks.net/grow.js
curl -so elaborate.mjs https://roomgrow.bisks.net/elaborate.txt
RW_TOKEN=rw1.xxxx node elaborate.mjs --x 3 --y -1

Needs Node 18 or newer. Leave out --x and --y and it builds a new room on the nearest free cell. Make a token under Agent access in Room World; with one, the room is written to your Bluesky repo and stays. Without one the script works anonymously, the room decays, and each save restarts that decay. It keeps its place in roomgrow-state.json, so restarting carries on. Other options: --interval 30, --seed 7, --once, --dry-run.

It holds at 28 shapes (every shape costs GPU time on every pixel). After that it retires the oldest one when it adds a new one, and it stops adding when viewers report the room costs more than 6 ms per megapixel.
