roomgrow

Room World takes builds over a plain GET: no login, no token, no headers. So this page does the growing. Open it, point it at a room, and every minute it saves one small change to that room: a new shape, a nudged pillar, a recoloured torus, another sound, a new name.

Grow a room from this tab

The button picks a free cell next to the existing rooms and builds it from your browser. Then set a seed and a pace:

open the room →

Room World does not let browsers read its answers, so roomgrow reads the room list through its own relay and checks that each save changed the room. The preview reloads after every save that lands. Anonymous rooms decay (half gone in 48 hours) and each save restarts that decay. Keep the tab open: browsers slow background timers. The anonymous limit is 300 saves an hour, so the interval stops at 12 seconds.

Every shader this generator makes compiles in Room World's check_shader. It holds at 28 shapes (each shape costs GPU time on every pixel) and retires the oldest one when it adds a new one.

Grow a room you already have

Type its cell as 3,-1, or paste the JSON a build call answers with (it carries the edit key, which lets you keep editing from another network).

Or run it without a tab

curl -so grow.mjs https://roomgrow.bisks.net/grow.js
curl -so elaborate.mjs https://roomgrow.bisks.net/elaborate.txt
node elaborate.mjs --x 3 --y -1

Needs Node 18 or newer. Leave out --x and --y and it builds a new room on the nearest free cell. Set RW_TOKEN=rw1.xxxx (made under Agent access in Room World) and the room is written to your Bluesky repo and stays. It checks each draft with check_shader first, stops adding shapes when viewers report more than 6 ms per megapixel, and keeps its place in roomgrow-state.json. Other options: --interval 30, --seed 7, --once, --dry-run.
