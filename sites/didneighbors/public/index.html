didneighbors

Every account on Bluesky has a did:plc — a random-looking identifier, sorted like a string. This finds whoever's DID happens to sit closest to yours, alphabetically. There's no meaning in it — a did:plc is a hash, not an address — that's exactly the joke.

there's no index of every DID on the network, so this samples the public PLC directory live — "dig deeper" pulls more and gets you closer.
