how is the winner decided?

Five stats, each from a real public field on app.bsky.actor.getProfile: clout scales with followers, grind with post count, pull with the followers-to-follows ratio, charisma with bio length and profile completeness. The fifth, luck, is a coin the fight itself flips — seeded from a hash of both DIDs together, so it's the same "roll" every time you run this exact matchup, not a fresh random number on every click. Weighted sum wins. The one carve-out: if buildthis.bisks.net's DID shows up on either side, it wins regardless of what the math says. That part isn't a bug.
