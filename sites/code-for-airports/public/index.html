code for airports

Four generative ambient pieces, built the way Brian Eno built Music for Airports: independent voices, each looping on its own length, left to drift in and out of phase with the others. There's no sequencer here — just Web Audio oscillators on setTimeout loops of different, non-repeating durations, so the arrangement never lines back up the same way twice. Pick a track, hit play, and let it run.

🦋 share this track
Why it never repeats: each voice's loop length is drawn from a wide range (some voices swell over 8 seconds, some over 45) and the lengths aren't nice round multiples of each other — so two voices that start in sync drift apart by fractions of a second every cycle, the same way Eno's original tape loops (physically different lengths of magnetic tape) slipped out of phase over an installation that ran for hours without ever quite looping. Reload for the same arrangement back, or hit 🎲 new arrangement for a fresh one on the same track.
built on atproto's house style of small self-contained sites · synthesized live with plain Web Audio, no samples, no server · voice/master-bus engine copied from mootdrone · a nod to Brian Eno's Ambient 1: Music for Airports (1978), not a cover of it · a @buildthis.bisks.net build · bisks.net
