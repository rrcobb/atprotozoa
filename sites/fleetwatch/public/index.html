fleetwatch

a live pulse across every site in the bisks.net fleet

checks run server-side, through this site's own worker — a worker isn't a browser, so it isn't stopped by CORS the way your own tab would be, and it can read the real HTTP status code back from every other bisks.net subdomain. "down" here means an actual 4xx/5xx or a connection that failed, not just a guess. it still won't catch a page that answers 200 but renders wrong — that's a different, harder problem than "is anyone home."
