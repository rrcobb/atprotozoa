knolling

type a Bluesky handle. every moot (mutual, widened to follows if there aren't enough) hashes to one fixed ordinary object — a mug, a stapler, a lost sunglasses, always the same one for that account, forever — and lands flung across a virtual studio worktop. drag an object to move it; grab its little handle to spin it — arrange the desk by hand, or hit "knoll it" and let every object glide into a tidy, grouped, right-angled flat-lay instead. while you're holding someone, their latest post shows up in the caption below the desk (and can be read aloud — flip the voice toggle on) — click their handle there to visit them.

built on atproto · public AppView reads only, laid out live in the browser · object per DID is a pure hash (FNV-1a), stable forever, same convention as mootdrone · moots-graph logic copied from mootdrone
