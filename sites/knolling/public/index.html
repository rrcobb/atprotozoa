knolling

type a Bluesky handle. every moot (mutual, widened to follows if there aren't enough) hashes to one fixed ordinary object — a mug, a stapler, a lost sunglasses, always the same one for that account, forever — and lands flung across a virtual studio worktop. hit "knoll it" and every object glides into a tidy, grouped, right-angled flat-lay. hover an object for who it is; click to visit them.

built on atproto · public AppView reads only, laid out live in the browser · object per DID is a pure hash (FNV-1a), stable forever, same convention as mootdrone · moots-graph logic copied from mootdrone
