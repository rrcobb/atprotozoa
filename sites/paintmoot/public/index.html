State is nothing but net.bisks.paintmoot.* records posted as you, the logged-in user — a board record for the canvas, a mark record per stroke, shape, text field, or emoji sticker. Anyone can start a board; a board's moots (its owner's mutual follows) can draw on it too. Everyone else gets a read-only view.
