🏷️ could intrigue be a labeler?

@fromthewestmeadow.com asked. Short answer below, then the actual working piece of it.

not a labeler — this page is only a static preview of a possible mapping.

A Bluesky labeler publishes signed (subject, label) pairs. Intrigue currently calculates scores locally in each visitor's browser and has no signing identity or network labeler endpoint, so there is nothing to subscribe to and no shared score data to publish.

the mapping

Every tier intrigue already shows on a score card becomes a label value:

scorelabel valuetier
90–100main-charactercertifiable main character
75–89intriguinggenuinely intriguing
55–74has-layershas layers
35–54quietly-finequietly fine
15–34lurkinglurking
0–14npccertified NPC

what "done" looks like

A future labeler would need a dedicated DID, signing key, service record, and a server that publishes labels. Until then this mapping remains documentation only.
