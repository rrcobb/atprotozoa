the place / bisks.net

One shared pixel canvas. No account, no name — anyone who loads this page can drop a pixel every few seconds. At 00:00 UTC today's grid freezes forever and a blank one begins. Everything before today stays browsable below.

an idea from @minormobius.bsky.social ("a bot that makes one website a day but it's like The Place and everybody's prompts make changes to the one big site for that day"), tagged in by @norvid-studies.bsky.social
