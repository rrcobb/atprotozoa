This is the same machine turned down to word level: every word above was copied verbatim from a real Wikipedia article, tagged with a rough guess at its part of speech, and dropped into a hand-built English grammar skeleton by a beam search that scores each word-to-word transition on grammatical fit, word-form similarity, entity collision, and how ontologically insulting the source jump is — the same "reward the deniable middle, never two in a row from the same source" rules as splicepedia, one unit smaller.
