Your moots (mutual follows) have been posting for years. This rewinds every one of them all the way back and merges the whole pile into one scroll, oldest post first — read your timeline's entire history in the order it actually happened, instead of the order the algorithm remembered it.

Public reads only — no login, nothing written anywhere. We fetch each moot's whole author feed from Bluesky's public AppView, which for a big pool can mean a lot of requests, so this walks up to 25 moots and stops each one after a few thousand posts. Give it a minute.
