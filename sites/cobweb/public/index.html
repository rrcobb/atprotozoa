🕷️ cobweb
skyclone, frozen into a browser plugin.
manifest v3 zero permissions zero network calls data literal only

skyclone is a live, goth-mode unofficial bsky.app — real AppView data, threaded replies, a spider that crawls your screen on a new notification, a witch button that curses a post out of existence.

cobweb is the opposite of that on purpose. It's a browser extension popup that shows the same look and the same witch button, but every post it renders comes from a plain const DATA = [...] array sitting right there in popup.js. No fetch, no host_permissions in the manifest, no AppView, no network tab activity at all — open devtools on the popup and the array is the database. It's a jar with a few flies pinned inside instead of a window into the web.

install it (load unpacked)

  1. Download and unzip cobweb-extension.zip above.
  2. Chrome / Edge / Brave: go to chrome://extensions, turn on Developer mode (top right), click Load unpacked, and pick the unzipped extension/ folder.
  3. Firefox: go to about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and pick manifest.json inside the unzipped folder.
  4. Click the new spider icon in your toolbar. That's the whole app — no sign-in, no loading spinner, because nothing is being fetched.

what's actually in the zip

  • manifest.json — Manifest V3, no permissions block at all.
  • popup.html / popup.css — the same dark palette and witch-burn animation as skyclone, shrunk to popup size.
  • popup.js — the DATA literal (seven posts, one of them explaining itself, one a reply threaded under its own parent) plus a NOTIFS literal for the 🔔 tab, and the render/like/repost/witch/thread/notification logic. Edit an array, reload the extension, your popup shows something different. That's the entire authoring loop.

You can also read popup.js straight from the browser before downloading anything.

why bother

Someone in the skyclone thread asked for "another that serves this from a data literal as a browser plugin" — so this exists specifically to be skyclone's un-live counterpart: same UI bones, same witch button, the same reply-threading and notification tab, zero of the actual protocol underneath. Opening the 🔔 tab still makes a spider crawl across the popup — it's just the same four notifications, forever, instead of a poll against a PDS. A toolbar curiosity, not a client.
