What this actually is: a plain browser WebSocket to jetstream2.us-east.bsky.network — every app.bsky.feed.post create event on the public firehose gets turned into a randomly-assembled trick name (real skate vocabulary mashed into coding-agent jargon, because apparently that's the bit) and bolted onto the current combo. Go quiet for a couple seconds and the combo lands, banking its score. When the firehose's post rate actually spikes — a real, measured burst, same rolling-average trick kolpelor uses for its World Pelor — the run stops faking it and lands the one trick that doesn't really exist: an indy nosebone, 50-50, fs rail grind, named-checking whichever real account's post rode the spike. Nothing is stored server-side; your score lives in this tab's localStorage only. Every trick also gets a synthesized Tony Hawk-style blip — off by default, hit the 🔇 button up top if you want the real firehose rate rendered as a cluttered cacophony of skate-game sound effects.
