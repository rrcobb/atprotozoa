firmware hub

a prototype directory for the custom-firmware explosion: cheap hardware, open replacement software. inspired by the FM-1 firmware hub.

Latest release tags come live from the GitHub API (cached for an hour in your browser) and show only when the project publishes GitHub releases. This site doesn't host or verify any firmware, and the synth, sampler and drum machine entries patch the official OS you download yourself (Elektron has asked its forum not to share such files, so check each maker's stance): follow each project's own install guide, and know that flashing can brick a device.
