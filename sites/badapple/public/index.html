badapple.bisks.net

the "does it run Bad Apple!!" test, but for whatever you point a camera at.

"Bad Apple!!" is a black-and-white silhouette music video that programmers have spent two decades getting to play on hardware and software it was never meant for — a graphing calculator, a spreadsheet, a printer, a git commit graph — as a running joke benchmark: "but can it run Bad Apple?" This page can't ship the actual video — it's someone else's copyrighted footage — so instead it runs your webcam or any video file you drop on it through the same silhouette treatment, live. Load the real thing from wherever you have it and see it happen, or just point it at yourself.
