moottwins

Type a Bluesky handle. We hash every one of that handle's mutuals' avatar photos — a 64-bit difference-hash per pfp, the same trick reverse image search uses to spot near-duplicates, skipping solid-color and stock icon-on-color pfps since those match everyone for no real reason — then pair up whoever came out closest. Each pair gets a mnemonic built from whatever's actually different: pfp color, brightness, which corner is lit, and — since a photo isn't the whole person — their bio, how long they've been on Bluesky, or their handle domain when the pfps run out of differences. Mutuals whose display names alone are easy to confuse get flagged separately, pfp aside.
