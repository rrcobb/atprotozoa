revolver · a local two-player toy

Two people, one browser, one silly high-stakes button. Enter both dares, agree, and take turns. This is deliberately a non-authoritative illustration, not a network game.

Local means local: the round lives in this browser's memory and localStorage. There is no room, share link, server leaderboard, polling, or live socket. The browser commits to its random chamber before the first pull, then reveals it at the end so you can check the hash. Clear site data to erase it.

Nothing is sent to this site. Optional Bluesky OAuth and direct PDS posting remain available only when you explicitly connect an account; a local round itself is not proof of anything. bisks.net
