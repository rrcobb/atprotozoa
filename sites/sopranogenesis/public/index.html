SOPRANOGENESIS

the two openings, fused

Someone asked for the Sopranos title sequence remade with the Neon Genesis Evangelion opening — same show, new grammar. This is that: an original animated title-card sequence built from scratch in CSS, not an edit of either show's actual footage or a copy of either theme song. It borrows the structure — the eye flash, the rapid-fire character name plates, the hex-grid command center, the silhouettes merging into machinery, the freeze on the walk forward — and reskins it with the Sopranos' cast and world.

Loop it above, or read the key below if you'd rather have the joke explained than watch it forty times.
