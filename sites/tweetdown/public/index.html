how does this work?

Both usernames get combined into a seed, so the same pair of names always draws the same six categories, the same winners, and the same lines — reroll by trying different names, not by refreshing. Whoever wins the most categories takes the showdown; a dead-even split goes to a sudden-death round. Nothing here reads a real account, a real tweet, or a real ratio — it's six made-up categories and a coin flip with good writing.
