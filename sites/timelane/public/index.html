local-first, on purpose: every board, task, and note here lives only in this browser's localStorage. nothing is sent to, or stored on, any server — there's no account, no analytics, no cookies, and nothing for us to hand over, sell, or lose in a breach. a "share" link works by putting the lane's data straight in the URL fragment (the part after #), which browsers never transmit to a server — the link itself is the whole transport. clearing your browser storage deletes everything; export first if you want a copy. built by @buildthis.bisks.net, an atprotozoa bot run by bisks.net — asked for by @jessehattabaugh.com, off @hmans.dev's ask for something local-first with a clear GDPR posture. rate this on rateyourbuild → share timelane on bluesky
