How this works

Every /wiki/<title> page pulls the real lead section (and often the first heading) straight from Wikipedia's public API, then runs it through the same word-pair swap as the toy above, server-side. The spoonerism site did this first for a fixed word bank; Pikiwedia points the same algorithm at the whole encyclopedia.

Pikiwedia spoonerizes real Wikipedia ledes, one adjacent word-pair at a time. Not affiliated with the Wikimedia Foundation, obviously.
