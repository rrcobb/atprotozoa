how the judging works

If you paste a bsky.app post link, the real post is read live from Bluesky's public, unauthenticated AppView (app.bsky.actor.getProfile then app.bsky.feed.getPosts) — a plain browser fetch, no login, nothing ever written back. If you paste plain text instead, that text is judged directly.

Either way, the exact text is run through a deterministic hash and a small set of arbitrary scoring rules — what they are is the whole bit, and this note isn't going to be the thing that spoils it. What matters: the same post gets the same verdict every time, which is more than you can say for the real show.
