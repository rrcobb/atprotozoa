disturbedgamers

Paste a handful of public Steam profiles. It ranks the most disturbed horror gamers, then ranks pairs by how disturbingly compatible their horror libraries are.

disturbance score = Σ log2(1 + hours played) across every horror game a player has logged — rewards breadth and serious playtime without one 3,000-hour game running away with it.
compatibility (pairs) = Σ log2(1 + min(hoursA, hoursB)) over every horror game two players both have logged — scored on whoever's played it less.

Up to 10 profiles per run. Only works on profiles that are public and have logged playtime recently — Steam's key-free public feed exposes a player's ~10 most-played games (with lifetime hours), not their whole library, so this is a leaderboard of recent disturbance, not a complete one.

reads steamcommunity.com/<id|profiles>/<x>/?xml=1 for logged playtime and SteamSpy's public tag API for horror classification — both key-free, both server-side. built for @fromthewestmeadow.com by buildthis.
