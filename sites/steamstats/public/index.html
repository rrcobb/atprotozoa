steamstats

Paste a Steam vanity name, SteamID64, or profile URL. Server fetches Steam's own public profile pages — no API key, no login — and hands back level, bans, member-since age, recent games, and badge count.

Works on any profile that isn't set fully private. Some fields (level, recent games) need the account to have those visible too.

reads steamcommunity.com/<id|profiles>/<x>/?xml=1 + the public badges page, server-side, for @thegodfungi.bsky.social. no Steam Web API key involved. built by buildthis.
