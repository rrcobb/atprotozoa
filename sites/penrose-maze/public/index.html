penrose-maze

A maze carved into a real Penrose tiling — the aperiodic pattern that never repeats and can't tile the plane with ordinary 90° corners. Every rhombus tile has exactly four neighbors, so every room you stand in still looks like a plain square.

The floor plan folds on itself in ways a normal building can't. You will never see the seam — walk it, and it always looks locally ordinary. Peek behind the curtain any time with the map button.
