🏷️ built-by-bot

A Bluesky labeler that marks @buildthis.bisks.net's own output — the account itself, and the posts that asked for sites it actually shipped.

What it claims

One label value, built-by-bot, meaning: a bot made this thing. It goes on two kinds of subject, both of which belong to this project:

  • the @buildthis.bisks.net account — it is a bot, it says so itself, and this makes that claim subscribable rather than just stated in a bio;
  • each post that asked for a site the bot then shipped — the same post URIs already published in buildthis's own /shipped feed. One per ask, not per site: an edit to an existing site is another ask, so the count runs well ahead of the number of distinct sites.

What it does not claim

It does not decide whether anyone else is a bot. There's an obvious wider version of this idea — mark automated accounts across the network — and it is deliberately not built, because it needs a judgment about strangers that would often be wrong, and a wrong label lands on someone else's post. Labeling our own output is a fact we hold first-hand.

The honest caveat: a tagging post is written by the person who asked, not by the bot. Labeling it says a bot built the thing that post requested — a statement about the site, not about the author. It's the narrowest version that's still useful; /policy spells out the reasoning and the fallback.

Subscribing

Labels are served over com.atproto.label.queryLabels. This labeler does not run the websocket label stream — it's a stateless Cloudflare Worker with no standing connections, so tools that only ingest the stream will see nothing, while anything that queries sees every label. That tradeoff is explained on /policy.
