Item #: SCP-021

Object Class: Euclid  ·  Cognitohazard

Special Containment Procedures

SCP-021 is confined to a single Cloudflare Worker instance addressed at https://biskshow.bisks.net/. No physical containment chamber is required. As a Euclid-class object, personnel are advised that SCP-021's behavior is only partially predictable under repeat interaction; researchers should log anomalous outputs to the site's own Addendum before treating them as expected behavior.

Description

SCP-021 — designated "biskshow" in Foundation records — classified as a recreational-hazard anomaly, is reachable at https://biskshow.bisks.net/.

Interviewed via its public interface, SCP-021 produced the following statement, transcribed verbatim:

a game-show guessing round: a mystery bisk drops in, you guess who posted it. solo mode quizzes you on a handle's follows; versus mode plays the set union of two handles' follows, with a share link for the matchup. @schwarzgerat.bsky.social asked for a game show.

Discovery Log

Foundation awareness of SCP-021 began with a tagged mention from the individual on record as @schwarzgerat.bsky.social. No discovery date is on record.

Addendum
