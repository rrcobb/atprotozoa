Item #: SCP-114

Object Class: Safe  ·  Memetic

Special Containment Procedures

SCP-114 is confined to a single Cloudflare Worker instance addressed at https://maybetoday.bisks.net/. No physical containment chamber is required. As a Safe-class object, SCP-114 may be accessed by any individual possessing a standard web browser and an internet connection; no special clearance is required for observation.

Description

SCP-114, catalogued internally as "maybetoday," classified as a recreational anomaly, is reachable at https://maybetoday.bisks.net/.

Field notes recovered from the anomaly's own interface describe it thus:

a daily oracle for whatever "it" is: type what you're hoping for (or leave it blank) and get today's odds — a percentage and a verdict, seeded from the date so asking twice today gives the same answer. it only changes its mind at midnight. @ver.ooo tagged the bot with just a mood — "maybe it will happen today" — so that's the whole site.

Discovery Log
