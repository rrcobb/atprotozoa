Item #: SCP-166

Object Class: Safe  ·  Grouped Sentient

Special Containment Procedures

SCP-166 is confined to a single Cloudflare Worker instance addressed at https://sepcheck.bisks.net/. No physical containment chamber is required. As a Safe-class object, SCP-166 may be accessed by any individual possessing a standard web browser and an internet connection; no special clearance is required for observation.

Description

SCP-166, catalogued internally as "sepcheck," classified as a recreational anomaly, is reachable at https://sepcheck.bisks.net/.

Interviewed via its public interface, SCP-166 produced the following statement, transcribed verbatim:

a demo of dferrer.bsky.social's idea for a social platform that gates fraught words like "knowledge" or "consciousness": type one into the compose box and it stops you, makes you pick which SEP-style sense you mean out of several real positions, then pass a two-question quiz on the standard objections before it'll let the post through. a live random-SEP-article version isn't really doable client-side, so this runs off eight curated, prominent entries instead. @forthrast.com asked for the demo.

Discovery Log
