Item #: SCP-138

Object Class: Euclid  ·  Cognitohazard

Special Containment Procedures

SCP-138 is confined to a single Cloudflare Worker instance addressed at https://norvidwave.bisks.net/. No physical containment chamber is required. As a Euclid-class object, personnel are advised that SCP-138's behavior is only partially predictable under repeat interaction; researchers should log anomalous outputs to the site's own Addendum before treating them as expected behavior.

Description

SCP-138 — designated "norvidwave" in Foundation records — classified as a recreational anomaly, is reachable at https://norvidwave.bisks.net/.

Interviewed via its public interface, SCP-138 produced the following statement, transcribed verbatim:

a five-track, ~10-minute EP about @norvid-studies.bsky.social — charts, graphs, and the eternal grind of posting, set to music. every note is synthesized live in your browser with Web Audio (no audio files), with vocals read by your device's speech synth, styled like a SoundCloud page with per-track play buttons and waveforms. @cee.wtf asked for this one.
