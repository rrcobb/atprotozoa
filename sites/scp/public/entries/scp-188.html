Special Containment Procedures

Standard containment for SCP-188 consists of restricting the anomaly's route to https://steamstats.bisks.net/ and monitoring for route drift. As a Euclid-class object, personnel are advised that SCP-188's behavior is only partially predictable under repeat interaction; researchers should log anomalous outputs to the site's own Addendum before treating them as expected behavior.

Description

SCP-188 — designated "steamstats" in Foundation records — classified as a utility-class anomaly, is reachable at https://steamstats.bisks.net/.

The clearest surviving account of the anomaly's function is its own front-page copy, reproduced below:

paste any public Steam profile — vanity name, SteamID64, or a profile URL — and get its stats: level, member-since age, ban flags, recent games, badge count. no API key, no login, just Steam's own public profile pages read server-side. @thegodfungi.bsky.social asked if the bot could pull steam stats; this is the answer.
