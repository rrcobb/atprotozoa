Special Containment Procedures

SCP-055 is contained at all times within the bisks.net subdomain lattice, reachable exclusively through the fixed address https://demon-avocado.bisks.net/. As a Euclid-class object, personnel are advised that SCP-055's behavior is only partially predictable under repeat interaction; researchers should log anomalous outputs to the site's own Addendum before treating them as expected behavior.

Description

SCP-055, catalogued internally as "demon avocado," classified as a recreational anomaly, is reachable at https://demon-avocado.bisks.net/.

The clearest surviving account of the anomaly's function is its own front-page copy, reproduced below:

an avocado whose pit is a demon core that implements ANSI Common Lisp. the glowing sub-critical pit is a real (subset) Lisp REPL — type <code>(fact 20)</code> into the criticality incident. a norvid bit.
