Item #: SCP-123

Object Class: Safe  ·  Temporal Info-Hazard

Special Containment Procedures

SCP-123 is confined to a single Cloudflare Worker instance addressed at https://moistchicken.bisks.net/. No physical containment chamber is required. As a Safe-class object, SCP-123 may be accessed by any individual possessing a standard web browser and an internet connection; no special clearance is required for observation.

Description

SCP-123 — designated "moist chicken" in Foundation records — classified as a utility-class anomaly, is reachable at https://moistchicken.bisks.net/.

Interviewed via its public interface, SCP-123 produced the following statement, transcribed verbatim:

top chicken's sibling: same follows-∪-followers network, but instead of a single best post it sums every like on every post the network made in the last 24 hours, divides by each account's follower count, and crowns the highest likes-per- follower — a small account blowing up beats a big one coasting on reach. @ver.ooo asked for this one.

Discovery Log

SCP-123 entered Foundation custody after being flagged by field asset @ver.ooo, whose transmission initiated standard containment procedure. First logged 2026-07-30.

Addendum

Addendum 123-A: Personnel are reminded that Safe classification describes containment difficulty, not triviality. Do not treat SCP-123 as uninteresting on this basis alone.
