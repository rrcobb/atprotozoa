Item #: SCP-208

Object Class: Euclid  ·  Self-Replicating

Special Containment Procedures

SCP-208 is confined to a single Cloudflare Worker instance addressed at https://wentviral.bisks.net/. No physical containment chamber is required. As a Euclid-class object, personnel are advised that SCP-208's behavior is only partially predictable under repeat interaction; researchers should log anomalous outputs to the site's own Addendum before treating them as expected behavior.

Description

SCP-208 — designated "wentviral" in Foundation records — classified as a recreational anomaly, is reachable at https://wentviral.bisks.net/.

Field notes recovered from the anomaly's own interface describe it thus:

fromthewestmeadow.com wanted a one-to-one Bluesky clone where you "post" whatever you want and watch it rack up replies, likes, reposts, and quote posts over time — so it built exactly that: a fake compose box whose entire pile-on is a seeded, deterministic function of your text and a timestamp, both baked into the share link, so a reload (or someone else opening it) reproduces the same growing thread with zero backend.

Discovery Log
