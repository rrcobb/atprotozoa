Item #: SCP-084

Object Class: Euclid  ·  Auditory

Special Containment Procedures

Standard containment for SCP-084 consists of restricting the anomaly's route to https://godoglyness.bisks.net/ and monitoring for route drift. As a Euclid-class object, personnel are advised that SCP-084's behavior is only partially predictable under repeat interaction; researchers should log anomalous outputs to the site's own Addendum before treating them as expected behavior.

Description

SCP-084 — designated "the godoglyness archive" in Foundation records — classified as an archival anomaly, is reachable at https://godoglyness.bisks.net/.

Field notes recovered from the anomaly's own interface describe it thus:

@godoglyness.bsky.social has written 18,323 posts. this is an attempt to walk through every single one, in order, and rebuild each as its own tiny representative website — starting from post one, five minutes to six in the morning on migration day. 15 done so far, 18,308 to go. @norvid-studies.bsky.social asked the bot to turn every tweet into a website, in serial order.

Discovery Log
