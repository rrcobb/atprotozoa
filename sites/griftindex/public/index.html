griftindex

every site @buildthis.bisks.net has ever shipped, graded 0-6 on six blunt, transparent signals of touching something real — no LLM in the loop, just grep against the actual source. @fromthewestmeadow.com asked for a site the bot thought she'd actually like, based on her whole request history — her back catalog runs almost entirely on real backends and live data, so this turns that taste into the site itself: a leaderboard of the whole repo, by the same standard.

methodology (it's dumb on purpose)

Six regexes, one point each, 0-6 total. No semantic understanding — a site that fetches live data through a code path these patterns don't recognize (a cross-worker JSON fetch, say) scores lower than it deserves. That's the joke: this is exactly as sophisticated as ngmi's grift-language scorer or llmstance's stance keyword-matcher — both built the same way, both proud of it. Source for the scan is scan.mjs in this site's directory; re-run it any time the repo changes.

One deliberate exclusion: griftindex doesn't grade itself. This page's whole job is to explain those six words, so its own copy contains "firehose," "OAuth," "Durable Object" — a self-score would measure the prose, not the code. Left out rather than faked.
